# XRPLendTrust — Demo Video Script

## Length
2 to 3 minutes. Hard ceiling: 3:00.

## The Voiceover Script

**Segment 1 — INTRO (0:00–0:20)**
"XRPLendTrust is a stand-alone lending integration for the XRP Ledger. It is built on XLS-65 and XLS-66. This is the full lifecycle, running on Devnet."

**Segment 2 — THE PROBLEM (0:20–0:40)**
"The XRP Ledger Lending Protocol brings native, uncollateralized credit to a public blockchain. It is in validator voting. XRPLendTrust is a working reference for what that protocol makes possible, built before the amendments go live."

**Segment 3 — THE DEMO (0:40–1:50)**
(Show the app running)
"Here is the client. The clock reads the real ledger time. The left column is the vault. The center is the loan desk. The right is the ledger."

"First, we deposit liquidity into the vault. This transaction is real. The hash is on Devnet."
(Point to the hash and the ledger column.)

"Next, we create the broker. The broker holds the first-loss capital. It takes 1 XRP of cover."
(Point to the broker card.)

"Now, a loan. The borrower requests 1 XRP. The broker signs first, then the borrower. The loan is active."
(Point to the loan card.)

"Finally, the repayment. The loan is paid in full. The vault's depositors are made whole."
(Point to the repayment hash.)

**Segment 4 — THE PROOF (1:50–2:30)**
"Every transaction is on the ledger. The hashes are in the proof folder. The repository is open. The code is MIT-licensed. You can clone it, run it, and verify every hash yourself."

(Show the GitHub repo, the README, the proof folder)

**Segment 5 — CLOSE (2:30–3:00)**
"XRPLendTrust. A working system with a face. Trust, on the ledger."

## Production Notes
- Use Windows Game Bar (Win+G) or OBS to record the screen.
- Read the voiceover aloud. Do not use a synthetic voice.
- Keep it simple. No fancy editing. Clipchamp is enough.
- Export at 1080p, H.264, under 200 MB.
